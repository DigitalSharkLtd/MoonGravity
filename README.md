# MOON GRAVITY — война за палладий

Стилизованный sci-fi **hero-шутер на Луне** (браузер / PWA / Android TWA). Две военные базы —
**ARTEMIS** и **SELENE** — воюют за палладиевый рудник у кратера Тихо. Лунная гравитация
(1,62 м/с²), магнитные ботинки для ходьбы по стенам и потолкам, скафандры с разгерметизацией и
удушьем, реактивные ранцы, крюк-кошка, дроны, сервиторы, турели, силовые поля и тактические
ядерные ракеты.

Стек: **three.js r186 (WebGL2) + TypeScript + Vite**, мультиплеер **listen-server на WebRTC**
(лобби/сигналинг — Netlify Functions + Blobs), без внешних ассетов: вся геометрия, PBR-текстуры,
музыка и большая часть звука генерируются процедурно.

## Режимы и карты

| Режим | Карта | Игроки | Цель |
|---|---|---|---|
| **Дуэль 2 × 2** | Аванпост «Дуэль» — два симметричных форпоста, рудник с мостами, ретрансляторы | 4 | 15 убийств |
| **Все против всех** | Карьер — 8 комплексов вокруг карьера (космопорт, купол-город, лаборатория, завод, силосы…) | 8 | 25 убийств |
| **Война 4 × 4** | Фронт Тихо — две звёздчатые крепости, точки A (завод) / B (буровая) / C (силосы) | 8 | 600 очков захвата |

Свободные слоты заполняются ботами (4 уровня сложности). Над картой периодически падают
капсулы снабжения с супероружием (тактический ядерный гранатомёт, сингулярность, орбитальный
лазер «Солнечное копьё»).

## Графика

Стилизованный PBR (rim/wrap-освещение), каскадные тени (CSM), N8AO, контурная обводка, bloom,
цветокоррекция с блеском солнца, SMAA, процедурные PBR-текстуры, запечённый свет в комплексах,
реголит с микрократерами. Меню настроек делит технологии на **тяжёлые / средние / лёгкие**:
AO, тени, SMAA, разрешение текстур, отражения, micro-detail рельефа, блики, плотность частиц,
motion blur, bloom, обводка, зерно, масштаб рендера.

Персонажи: единая «эталонная» сетка скафандра (mid-poly, плавные веса скиннинга на суставах),
жёсткие элементы брони на костях, IK рук для хвата оружия, процедурные анимации с учётом лунной
гравитации (лёгкий бег-подскок, длинные прыжки, приземления, подкат, кувырок, положение лёжа,
вскарабкивание, крюк).

## Запуск локально

```sh
npm install
npm run dev          # http://localhost:5173 — лобби для мультиплеера работает прямо в dev-сервере
npm run build        # production-сборка в dist/ (с typecheck)
npm run preview      # раздача dist/ + локальное лобби
npm run dist         # сборка + release/moon-gravity-netlify-drop.zip
```

Мультиплеер локально: откройте игру в двух вкладках — первая создаст комнату (listen-server),
вторая найдёт её через «Быструю игру» или по ссылке-приглашению `…/#join=<код>`.

## Деплой на Netlify

**С мультиплеером (рекомендуется):** подключите репозиторий в Netlify (или `netlify deploy`
через CLI). `netlify.toml` уже настроен: сборка `npm run build`, публикация `dist/`, функция
`netlify/functions/lobby.mts` (`/api/lobby/*`) на Netlify Blobs — матчмейкинг и сигналинг WebRTC.
Игровой трафик идёт напрямую между игроками (P2P), не через Netlify.

**Netlify Drop:** `npm run dist` → перетащите `release/moon-gravity-netlify-drop.zip`
(или папку `dist/`) на <https://app.netlify.com/drop>. Drop не запускает Functions, поэтому
онлайн-лобби там недоступно — игра автоматически предложит матчи с ботами.

Хост комнаты — сам игрок (listen server): до 8 мест; быстрый поиск заполняет первую
незаполненную комнату, затем следующую; пустые места занимают боты.

## Приложение (PWA / Android)

Игра — полноценное PWA: манифест (fullscreen, landscape, maskable-иконки), service worker с
предзагрузкой всех ассетов — после первого запуска стартует **офлайн** (с ботами). В меню
появляется пункт «Установить приложение». Для Google Play — Trusted Web Activity, инструкция в
[`twa/README.md`](twa/README.md) (Bubblewrap, `assetlinks.json`).

## Структура

```
src/
  core/      физика (коллайдеры, heightfield, raycast), ввод, шум
  entities/  тело с лунной физикой и маг-ботинками, модели героев (скелет, SuitMesh, IK)
  game/      Game (цикл 60 Гц), Combat, Abilities, Summons, Vitals, Match, Bots, Nav, Viewmodel
  net/       NetGame (протокол, снапшоты, авторитет хоста), Lobby/Transport (WebRTC)
  render/    Pipeline (постэффекты), материалы, процедурные текстуры
  world/     рельеф, небо, освещение, кит строений, комплексы, карты
  ui/        меню, профиль, HUD, i18n (RU/EN)
  audio/     гибридный движок (синтез + сэмплы), музыка
  pwa/       service worker, установка
netlify/functions/lobby.mts   лобби/сигналинг (Netlify Functions v2 + Blobs)
shared/lobbyCore.ts           общая логика лобби (функция и dev-сервер)
twa/                          шаблон Android TWA
```

Тестовые стенды (только dev): `game-test.html` (матч без UI, `?lineup&pose=…` — смотр героев и
анимаций), `world-preview.html` (карты), `ui-preview.html` (экраны интерфейса).
